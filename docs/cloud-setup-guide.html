طرق تفعيل الحسابات وتسجيل الدخول في Firebase

يدعم مشروع المنصة في Firebase عدة طرق مرنة وآمنة لتفعيل حسابات المعلمين والطلاب وتأكيد هوياتهم:

أولاً: تفعيل الدخول السريع بحساب Google (مُفعّل وجاهز ✅)

  • الفكرة: لا يحتاج المستخدم إلى كتابة كلمة سر أو تفعيل بالبريد، لأن حساب Google موثق مسبقاً وتؤكده Google تلقائياً.
  • كيف تم إعداده؟
    1. من لوحة Firebase ➔ Authentication ➔ تبويب Sign-in method.
    2. الضغط على مزود Google ➔ تفعيل Enable.
    3. تحديد البريد الإلكتروني للدعم (Project support email) ➔ الضغط على Save.
  • في كود المنصة: تم تفعيل زر الدخول بحساب Google ويستدعي signInWithPopup(auth, googleProvider).

ثانياً: تفعيل الدخول بحساب GitHub (خطوات الربط بين Firebase و GitHub)

يتيح هذا الخيار للمعلمين والطلاب التقنيين تسجيل الدخول بحساباتهم البرمجية على GitHub بنقرة واحدة:

1
الحصول على رابط إعادة التوجيه من Firebase (Callback URL) ادخل إلى لوحة Firebase ➔ Authentication ➔ Sign-in method ➔ اضغط على مزود GitHub:
ستجد رابطاً ينتهي بـ: /__/auth/handler (انسخه).
2
إنشاء تطبيق OAuth في حسابك على GitHub ادخل إلى GitHub ➔ Settings ➔ Developer settings ➔ OAuth Apps ➔ اضغط New OAuth App:
  • Application name: Smart Edu Platform
  • Homepage URL: https://edu-platform-ye.netlify.app
  • Authorization callback URL: الصق الرابط المنسوخ من Firebase في الخطوة 1.
  • اضغط Register application.
3
ربط المفاتيح في Firebase في صفحة تطبيق GitHub الجديد، انسخ Client ID، واضغط على Generate a new client secret وانسخ الـ Secret.
ارجع إلى صفحة Firebase والصقهما في خانتي (Client ID و Client secret) ثم اضغط Save.

ثالثاً: تفعيل رسالة تأكيد البريد الإلكتروني (Email Verification / Activation)

عندما يسجل مستخدم ببريد إلكتروني وكلمة مرور، يمكنك إلزامه بالنقر على رابط تفعيل يصل إلى بريده الإلكتروني:

  • طريقة تفعيل الرسالة في الكود: بعد استدعاء createUserWithEmailAndPassword، يتم استدعاء دالة: 
    import { sendEmailVerification } from "firebase/auth";
await sendEmailVerification(auth.currentUser);
  • تخصيص نص رسالة التفعيل بالعربية:
    1. من لوحة Firebase ➔ Authentication ➔ تبويب Templates (القوالب).
    2. اختر Email address verification واضغط على أيقونة القلم ✏️.
    3. غيّر عنوان الرسالة إلى: تفعيل حسابك في منظومة التعليم الذكية.
    4. غيّر نص الرسالة بالعربية واضغط Save.

رابعاً: الدخول السريع برابط البريد دون كلمة مرور (Passwordless Sign-in)

من لوحة Firebase ➔ Authentication ➔ اضغط على Email/Password، وفعّل خيار Email link (passwordless sign-in) ثم احفظ. هذا الخيار يرسل للمستخدم رابطاً آمناً إلى بريده بمجرد كتابته، يضغط عليه فيدخل مباشرة للمنصة دون كلمة سر!

ربط مشروع Firebase مع GitHub و Google (الأتمتة والنشر)

لربط المنظومة السحابية بحيث يتم نشر وتحديث كل شيء تلقائياً بين Google و Firebase و GitHub:

1. ربط مستودع GitHub بنظام النشر التلقائي في Firebase Hosting:

إذا أردت مستقبلاً أن يُنشر موقعك على Firebase Hosting تلقائياً عند تنفيذ git push على مستودع GitHub:

1
توليد مفتاح خدمة النشر (Service Account Key) من لوحة Firebase ➔ Project settings (أيقونة الترس) ➔ تبويب Service accounts ➔ اضغط على Generate new private key.
2
إضافة المفتاح إلى GitHub Secrets في مستودع GitHub الخاص بك (asil775lil-svg/edu-platform) ➔ Settings ➔ Secrets and variables ➔ Actions ➔ New repository secret:
سمّه: FIREBASE_SERVICE_ACCOUNT_SMART_EDUCATION_ED253 والصق محتوى المفتاح.
3
تشغيل سير العمل التلقائي (GitHub Action) يتم إنشاء ملف .github/workflows/firebase-deploy.yml ليقوم تلقائياً ببناء المنصة ورفعها لفايربيس مع كل تحديث ترسله!

2. ربط المنظومة مع Google Cloud APIs (لخدمات Google Drive و AI):

  • مشروعك smart-education-ed253 هو مشروع متكامل بين Firebase و Google Cloud Platform.
  • أي خدمة من جوجل تريد تفعيلها (مثل Google Drive API أو Gemini AI) تفعّلها مباشرة لنفس المشروع من:
    https://console.cloud.google.com/apis/library?project=smart-education-ed253

خطوات التحديث التلقائي الشامل عبر GitHub و Google Drive

المسار الأول: التحديث التلقائي للكود والخادم عبر GitHub 🚀

أي تحسين أو تعديل تجريه على المنصة في جهازك، يُنشر للإنترنت تلقائياً بهذه الخطوات الثلاث البسيطة في PowerShell:

# 1. تجميع كل الملفات المعدلة
git add .

# 2. كتابة وصف لما تم تعديله
git commit -m "إضافة ميزات وتحديثات جديدة للمنصة"

# 3. إرسال التحديث للسحابة
git push origin main
ماذا يحدث بعد أمر `git push` تلقائياً؟
• سحابة Render ترصد التحديث وتبدأ إعادة بناء الخادم ونشر الـ API السحابي الجديد خلال دقيقة واحدة دون توقف الموقع.
• مستودع GitHub يحفظ أحدث نسخة احتياطية من كودك بشكل دائم ومشفر.

المسار الثاني: التحديث التلقائي للمناهج والدروس عبر Google Drive 📁

يتيح للمعلم إضافة الدروس وتعديل الفيديوهات والملفات في مجلد المادة على Google Drive لتتحدث في المنصة فوراً:

1
تفعيل Google Drive API في وحدة تحكم Google Cloud لنفس المشروع، يتم تفعيل مكتبة Google Drive API.
2
ربط مجلد المنهج (Folder Sync) يقوم المعلم بمشاركة مجلد المادة على Google Drive مع بريد الخدمة (Service Account) الخاص بالمنصة، أو تحديد معرف المجلد (Folder ID).
3
إشعار التغييرات اللحظي (Google Drive Push Notifications - Webhooks) يقوم الخادم بتسجيل اشتراك مراقبة (Watch Request). عند قيام المعلم بحفظ أو إضافة أي درس أو فيديو جديد في درايف:
ترسل جوجل إشعاراً فورياً (Webhook POST) إلى خادم المنصة:
https://edu-platform-67ju.onrender.com/api/integrations/gdrive-webhook
4
التحديث التلقائي ونشر حزمة (.edupkg) يقوم الخادم السحابي بقراءة الملفات المحدثة، دمجها في مسودة المنهج courses.draft، وتوليد نسخة ثابتة جديدة موثوقة (Published Version)، لتصل لجميع الطلاب فور فتحهم للمنصة!
حل بديل مباشر (المزامنة المكتبية ببرنامج Google Drive):
إذا كان المعلم يملك تطبيق Google Drive للكمبيوتر، فإن مجلد درايف يظهر كمجلد محلي في جهازه. وتتيح ميزة "استيراد مجلد" المدمجة في المنصة استيراد وتحديث المنهج كاملاً بضغطة زر دون الحاجة لأي مفاتيح برمجية!
